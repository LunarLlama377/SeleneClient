# Forking Selene Client

Selene Client is an open-source Minecraft 1.8.9 PvP utility client developed by **LunarLlama377**.

We encourage developers to fork, modify, improve, and build upon Selene Client. However, all derivative projects must follow the attribution guidelines below.

## 1. Attribution Requirements

All forks and derivative projects must visibly credit the original project.

The required attribution format is:

**"[Client Name] — A branch of Selene Client by LunarLlama377"**

This attribution must be included in the derivative project's README, documentation, or another clearly visible location.

## 2. Modification Rights

Developers are permitted to:

- Modify existing features.
- Add entirely new features.
- Remove existing features.
- Change the user interface and design.
- Create independently branded clients.
- Distribute their modified versions.
- Publish their own source code.

## 3. Naming and Branding

Forks may use their own names, logos, themes, and branding.

However, derivative projects must not claim to be the official Selene Client or imply endorsement by the original developer.

## 4. Distribution

Developers may distribute their forks publicly, including compiled releases and source code.

All distributions must retain the applicable copyright and license notices.

## 5. Original Project

The original Selene Client project is maintained by **LunarLlama377**.
