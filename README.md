# Selene Client
Selene Client is a PVP Utility client for 1.8.9 that gives users helpful features for gameplay. It is similar to others such as [Badlion](https://www.badlion.net/), [Lunar](https://www.lunarclient.com/), etc. We (Lunar and others who work on the project) are not responsible for any punishments given from using any of the above clients or ours. Right now we some core features such as Combat stats, Potion timers, CPS/Keystrokes, Togglesprint, etc. We hope to add more features in the not-too-distant future. We are not associated with [Lunar Client](https://www.lunarclient.com/) or Moonsworth.
